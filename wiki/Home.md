## Project Overview

**M8 Business Suite** is a marketing and business management dashboard built with:
- **Next.js 14** - React framework
- **React 18** - UI library
- **Supabase** - Backend & database
- **Tailwind CSS** - Styling

**Live Demo:** https://m8b.vercel.app
